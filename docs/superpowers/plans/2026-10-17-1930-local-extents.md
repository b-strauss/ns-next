# Local extents for an error-free parse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On a parse without an error, attach comments without the
prepass and the loop over every commentable node: each child's extent is
read from the child itself when its parent is expanded.

**Architecture:** The parser records the empty parts and the pattern
literals the prepass collects today (`attach::Exclusions`, rolled back
with its checkpoints). `attach.rs` gets a second path, `attach_clean`,
whose descent asks `local_extent` for each child's extent instead of the
pre-order entries; a parse with an error keeps today's walk. A debug
build checks every local attachment against the walk.

**Tech Stack:** Rust 1.98, `crates/ns-syntax` only.

**Spec:** `docs/superpowers/specs/2026-10-17-local-extents-design.md`

## Global Constraints

- The rules of `attach.rs`'s module documentation do not change; every
  `AttachedComment` of every source stays as it is.
- `attach_comments`' signature stays; the walk path is today's code.
- No change to the AST (`ast.rs`).
- Never recurse along a receiver: `local_extent` of an `Expression` asks
  no child.
- Names are written out (`CLAUDE.md`, "Conventions"); comments explain
  the decision.
- Commit gates: `cargo xtask gates commit` before every commit that
  changes more than Markdown. End of the batch: `cargo xtask gates
  end-of-batch` (`ns-syntax` is "the runtime").
- `lexer.rs` is not touched, so the plugin's lexer has nothing to mirror.
- Conventional commits, each ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01RRpMXsUbvJ9BUg9se8QKwP`.

## Review Focus

1. A speculative parse that is rolled back (`parse_slot_declarations`'
   `||` attempt, the member speculation) must leave no exclusion behind:
   the checkpoint carries the lists' lengths. Pinned by Task 1's
   comparison over every source.
2. A nested pattern literal (`<at: <x: 1>>`) records only the outer
   literal: `inside_a_pattern` looks at the last pattern starting before
   a comment. Pinned by Task 1's test `a_nested_pattern_is_recorded_once`.
3. A source that lexes with an error but parses (`parse_for_editor`)
   must take the walk. Pinned in a debug build by the oracle over every
   prefix: a prefix sent down the clean path by mistake meets the debug
   comparison against the walk.
4. An implicit receiver (`synthesized`) has no extent on either path.
   Covered by the oracle (every golden has implicit sends).
5. A `CodeBody` with temporaries and no statement, or statements and no
   temporaries: its local extent takes its first and last child of
   either list. Pinned by Task 3's `a_body_s_extent_spans_its_first_and_last_child`.

- [ ] **Step 2: The parser's field and checkpoint.** In `parser/mod.rs`

```rust
/// Where a speculative parse started, so that [`Parser::restore`] undoes
/// everything it did: the cursor, its diagnostics and the exclusions it
/// recorded.
#[derive(Clone, Copy)]
pub(crate) struct Checkpoint {
    pub(crate) position: usize,
    pub(crate) diagnostics: usize,
    empty_bars: usize,
    empty_class_sides: usize,
    patterns: usize,
}

pub(crate) fn checkpoint(&self) -> Checkpoint {
    Checkpoint {
        position: self.position,
        diagnostics: self.diagnostics.len(),
        empty_bars: self.exclusions.empty_bars.len(),
        empty_class_sides: self.exclusions.empty_class_sides.len(),
        patterns: self.exclusions.patterns.len(),
    }
}

pub(crate) fn restore(&mut self, checkpoint: Checkpoint) {
    self.position = checkpoint.position;
    self.diagnostics.truncate(checkpoint.diagnostics);
    self.exclusions.empty_bars.truncate(checkpoint.empty_bars);
    self.exclusions.empty_class_sides.truncate(checkpoint.empty_class_sides);
    self.exclusions.patterns.truncate(checkpoint.patterns);
}

/// The exclusions recorded so far, for the attachment's clean path.
pub(crate) fn take_exclusions(&mut self) -> crate::attach::Exclusions {
    std::mem::take(&mut self.exclusions)
}
```

Keep the doc comment of `restore` up to date. Replace every `checkpoint.0`
with `checkpoint.position` and `checkpoint.1` with
`checkpoint.diagnostics` (`grep -n "checkpoint\.[01]" crates/ns-syntax/src/parser/`).

`restore` (`grep -n "self.position = " crates/ns-syntax/src/parser/`):
read it; if what it rewinds can have recorded an exclusion, take a

`Parts::from_exclusions` builds the `Parts` the clean path uses:

```rust
/// The parts of a clean parse, from what the parser recorded: each empty
/// part dropped by the test the prepass applies.
fn from_exclusions(
    tokens: &'input [Token],
    comments: &'input [Comment],
    exclusions: &Exclusions,
) -> Parts<'input> {
    let mut parts = Parts::new(tokens, comments);
    for delimiters in &exclusions.empty_bars {
        parts.drop_if_empty(Some(*delimiters));
    }
    for delimiters in &exclusions.empty_class_sides {
        parts.drop_empty_class_side(Some(*delimiters));
    }
    parts.patterns.extend_from_slice(&exclusions.patterns);
    parts
}
```

and `drop_empty_class_side` is `describe_class`'s block moved into a
method of `Parts` (the side's tokens and its `:`), `describe_class` then
calling it: `if side.members.is_empty() { parts.drop_empty_class_side(side.delimiters); }`.
`Span` needs `PartialEq` for the comparison; it has it.

- [ ] **Step 2: `local_extent`.**

```rust
/// A node's extent read from the node itself, for the clean path: on a
/// parse without an error an expression, a block, a class, a method, a
/// superclass clause and a class side span their subtrees, so the tokens
/// covering what the node knows are its extent; a statement, a slot, a
/// message and a body know less than they span and take their children's
/// extents, each read the same way. An expression asks no child, so no
/// chain of messages is followed.
fn local_extent(node: Node<'_>, tokens: &Tokens, work: &mut usize) -> Option<(usize, usize)> {
    *work += 1;
    let (known, shape) = known_and_shape(node);
    let mut extents = |nodes: &mut dyn Iterator<Item = Node<'_>>| {
        nodes
            .filter_map(|child| local_extent(child, tokens, work))
            .reduce(merge)
    };
    let children = match node {
        Node::Statement(statement) => {
            let (StatementKind::Return(expression) | StatementKind::Expression(expression)) =
                &statement.kind;
            extents(&mut std::iter::once(Node::Expression(expression)))
        }
        Node::Slot(slot) => extents(&mut slot.initializer.iter().map(Node::Expression)),
        Node::Message(message) => extents(&mut message.arguments.iter().map(Node::Expression)),
        Node::Body(body) => {
            // Its children stand in source order: the first and the last
            // are its extent's ends.
            let first = body
                .temporaries
                .first()
                .map(Node::Slot)
                .or_else(|| body.statements.first().map(Node::Statement));
            let last = body
                .statements
                .last()
                .map(Node::Statement)
                .or_else(|| body.temporaries.last().map(Node::Slot));
            extents(&mut first.into_iter().chain(last))
        }
        _ => None,
    };
    extent_of(tokens, &mut Cursors::default(), known, shape, children)
}
```

The `extents` helper's form is free: whatever the borrow checker accepts
that merges the children's local extents. Make
`Tokens::covering` available outside `#[cfg(test)]` only if
`extent_of`'s `covering_near` from fresh `Cursors` measures slower;
otherwise leave it.

- [ ] **Step 4: The entry.**

```rust
/// [`attach_comments`] for a parse without an error, given what the parser
/// recorded: no prepass and no extents measured ahead, each child's extent
/// read from the child when its parent is expanded (`local_extent`). A
/// debug build attaches a copy by the walk as well and holds the two
/// equal, so every clean parse of the debug suites checks the claim
/// `local_extent` rests on.
pub(crate) fn attach_clean_comments(
    module: &mut Module,
    tokens: &[Token],
    comments: &[Comment],
    source: &str,
    exclusions: &Exclusions,
) {
    #[cfg(debug_assertions)]
    let mut walked = module.clone();
    attach_clean(module, tokens, comments, source, exclusions);
    #[cfg(debug_assertions)]
    {
        attach(&mut walked, tokens, comments, source);
        assert!(*module == walked, "the clean path attached unlike the walk");
    }
}

fn attach_clean(
    module: &mut Module,
    tokens: &[Token],
    comments: &[Comment],
    source: &str,
    exclusions: &Exclusions,
) -> usize {
    if comments.is_empty() {
        return 0;
    }
    let mut work = 0;
    let (dropped, patterns) = Parts::from_exclusions(tokens, comments, exclusions).sorted();
    let kept = Tokens::kept(tokens, &dropped);
    let placed = (0..comments.len())
        .filter(|index| !inside_a_pattern(&patterns, comments[*index].span))
        .collect();
    let context = Context {
        tokens: &kept,
        entries: None,
        comments,
        source,
    };
    descend(module, &context, placed, &mut work);
    work
}
```

The debug comparison runs only when `comments` is not empty (clone
after the early return, or check first) so a module without a comment
costs no clone.
