# Debugger Stage 1: the Debugging API at the Safepoint — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A host can attach a debugger to an `Interpreter`, pause a running program from another thread, read its stack and values while it is stopped at the run loop's safepoint, and continue or terminate it; commands queued while it runs are served at the next safepoint.

**Architecture:** The heap's machine words become atomics shared through an `Arc`, and the safepoint request word a set of bits, so a `Send` handle (`DebugRemote`) can arm the poll from another thread (decision 7). `Interpreter::safepoint` serves the debugger first: it drains the command queue and, on a pause, deoptimizes a stop at an optimized poll and blocks on a channel serving commands until `Continue` or `Terminate` (decision 9). Stack and values are read from the activation stack without metadata (stage 2 brings names and lines), values handed out as ids of `Root`s held for the stop.

**Tech Stack:** Rust 1.98.0 (edition 2021), `std::sync::{Arc, atomic, mpsc}`, `cargo-nextest`; no new dependency.

**Spec:** `docs/design/debugger.md` — "Planned: the decisions" 1, 7 and 9; "Planned: the mechanisms": "The poll words as atomics", "Commands while the program runs", "Reading the stack at a stop", "Values the IDE holds", "Writing a frame" (only the read side here); "Planned: the order of building it", stage 1.

## Global Constraints

- `ns-runtime` forbids `unsafe` (`lib.rs:4`); everything here is safe Rust. No new external dependency.
- Names are written out (`CLAUDE.md`, Conventions): no identifier of one or two characters, no truncation (`program_counter`, not `pc`).
- Never `{:?}` a `Value`, never `.unwrap()`/`.expect()`/`{:?}` an `EvaluationResult`; tests use a local `expect_ok` helper copied from a neighbour (e.g. `crates/ns-runtime/tests/stress.rs:7-31`).
- A Newspeak module inline in a test is an `indoc! {"…"}` indented with the Rust around it, the closing `"}` on its own line.
- Object, frame and activation access goes through `crates/ns-runtime/src/heap.rs`; a missing accessor is added there.
- A `Symbol` is thread-local (`crates/ns-cli/src/main.rs:191-193`): nothing that crosses to the agent's thread carries a `Symbol`, a `Value`, a `Root` or a handle — only `String`s, numbers, `Span`s and `ValueId`s.
- `vm.rs` holds no dispatch logic; the debugger's code lives in a new module `crates/ns-runtime/src/debugger/`, called from `interpreter/safepoint.rs`.
- Every commit runs `cargo xtask gates commit`; a commit touching `vm.rs`, `heap.rs` or `interpreter/mod.rs` also `cargo xtask gates codegen`. The batch ends with `cargo xtask gates end-of-batch` (`CLAUDE.md`, "The gates"); a commit before that is work in progress.
- Comments explain the decision, not the mechanics. Docs describe the current state.

## Review Focus

1. **A pause while a collection request is pending:** `Interpreter::safepoint` returns early while a collection stays requested (step 7 of its body); the pause must still be served, at that safepoint, not lost — pinned in Task 3.
2. **A pause in compiled recursion with no loop:** the prologues compare only `DepthLimit`; the pause must stop such a program — pinned in Task 5 (`a_pause_stops_compiled_recursion`).
3. **The agent vanishing:** a `DebugRemote` dropped while the program runs or while it is stopped must let the program run to its end, never hang it — pinned in Task 3.
4. **Reading a frame's dead registers:** a register the leftover analysis finds tainted at the frame's `program_counter` (or a debug build's poison word) must never be read — `activation_local` asserts liveness in a debug build; pinned by the pause stress mode over every golden (Task 6).
5. **Terminating with `ensure:` blocks pending:** `Terminate` at a stop must run the pending `ensure:` blocks as the `terminate…` leaf's termination does — pinned in Task 3.

**Files:**
- Create: `crates/ns-runtime/src/debugger/mod.rs` (the VM side: `Debugger`, serving at the safepoint), `crates/ns-runtime/src/debugger/remote.rs` (`DebugRemote`, `Command`, `Event`, `StopReason`, `ValueId` and the description types of Task 4)
- Modify: `crates/ns-runtime/src/lib.rs` (`mod debugger; pub use debugger::{…}`), `crates/ns-runtime/src/interpreter/mod.rs` (`Interpreter` gets `debugger: Option<Debugger>`; `pub fn attach_debugger(&mut self) -> DebugRemote`), `crates/ns-runtime/src/interpreter/safepoint.rs` (serve the debugger first; the return type), `crates/ns-runtime/src/vm.rs` (`run`'s handling of the outcome, l.218-277), `crates/ns-runtime/src/jit/mod.rs` (`deoptimize_stopped_at_poll`'s `cfg` widened to every `ns_jit` build, its non-JIT twin to every build; the `StoppedAtPoll` doc's "neither a mirror nor a debugger reads a frame there" corrected)
- Test: `crates/ns-runtime/tests/debugger.rs`

**Interfaces:**
- Produces (all `pub`, re-exported from the crate root):
  - `DebugRemote` (`Send`): `pause(&self)` — `fetch_or(DEBUGGER_PAUSE)` then `DepthLimit` 0, both `SeqCst`; `send(&self, command: Command)` — queue first, then `fetch_or(DEBUGGER_COMMANDS)` and `DepthLimit` 0; `next_event(&self, timeout: Duration) -> Option<Event>`.
  - `enum Command { Continue, Terminate, StackTrace, Variables { frame: usize }, Children { value: ValueId, start: usize, count: usize } }`.
  - `enum Event { Stopped { reason: StopReason }, StackTrace(Vec<FrameDescription>), Variables(Vec<Variable>), Refused { command: String, reason: String }, Continued }`.
  - `enum StopReason { Pause }`; `#[derive(Clone, Copy, PartialEq, Eq)] struct ValueId(u32)`.
  - The description types `FrameDescription`, `FrameKind`, `Variable` and `ValueDescription` are declared here as Task 4 specifies them, so `Event` compiles; Task 4 fills them.
  - `pub(crate) enum SafepointOutcome { Unchanged, Rebuilt, Terminate }`, answered by `Interpreter::safepoint(&mut self, floor: usize)`.
- Behaviour:
  - At the top of `Interpreter::safepoint`, before the stress modes and the collections: if the word has `DEBUGGER_COMMANDS`, clear that bit first, then drain the queue (`try_recv`): `Terminate` answers `SafepointOutcome::Terminate`; a stop-only command is answered `Event::Refused`. If the word has `DEBUGGER_PAUSE`: clear it, `jit::deoptimize_stopped_at_poll`, send `Event::Stopped { reason: Pause }`, then block on `recv` serving commands until `Continue` (send `Event::Continued`, drop the stop's values, go on with the rest of the safepoint) or `Terminate`.
  - A disconnected queue (the remote dropped) detaches the debugger: `Interpreter.debugger = None`, the program runs on; while stopped it is a `Continue`.
  - `SafepointOutcome::Terminate` makes `vm::run` end the run through the unwinder as the `terminate…` leaf's `Signal::Terminate` does (`interpreter/unwind.rs:222`), raised in the top activation, with the error message `the debugger terminated the program`, so `ensure:` blocks run and the host sees `HostSignal::Error`.
  - A pause requested while no run executes stops the next run at its first safepoint.

### Task 4: Reading the stack and values at a stop

**Files:**
- Create: `crates/ns-runtime/src/debugger/stack.rs` (frames), `crates/ns-runtime/src/debugger/values.rs` (the stop's value table, descriptions, children)
- Modify: `crates/ns-runtime/src/debugger/mod.rs`, `remote.rs` (the description types), `crates/ns-runtime/src/heap.rs` only for a missing accessor (e.g. a register read that does not assert liveness is **not** added: only untainted registers are read)
- Test: `crates/ns-runtime/tests/debugger.rs`

**Interfaces:**
- Produces (in `remote.rs`, `pub`):
  - `struct FrameDescription { pub kind: FrameKind, pub program_counter: usize, pub source: ns_syntax::Span, pub receiver: ValueDescription }`, innermost first.
  - `enum FrameKind { Method { selector: String }, Block, Initializer, SuperclassClause, Factory, TopLevel }` — from `Heap::activation_kind` (`types.rs:383`).
  - `struct Variable { pub name: String, pub value: ValueDescription }`.
  - `struct ValueDescription { pub id: ValueId, pub label: String, pub class_name: String, pub child_count: usize }` — `label` from `Heap::describe`, `class_name` from `Heap::class_display_name` of `Mutator::class_of`.
- Behaviour:
  - `StackTrace` walks from `Heap::top_activation` by `activation_sender`, down to the run's floor, and answers one `FrameDescription` per activation, `source` the body's `CompiledCode::source`.
  - `Variables { frame }` answers, for the frame at that index: `self` (the receiver), then each argument as `argument 1` … `argument N`, then each register from the argument count up to `local_count` that the leftover analysis does not find tainted before the frame's stored `program_counter` (`TaintedSets::before`, as `Heap::trace_stack` asks it) as `register K`; a tainted register is left out. An index past the stack answers `Refused`.
  - `Children { value, start, count }` answers `Variables`: an instance's fields as `field 0` … (`instance_fields`), an `Array`'s elements as `[1]` … (`array_element`), paged by `start`/`count`; anything else none. An unknown or stale `ValueId` answers `Refused`.
  - Every value handed out is stashed as a `Root` in the stop's table and named by its index; `Continue` and `Terminate` drop the table, so the ids of one stop never name a value at the next.
